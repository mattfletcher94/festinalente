# Communication Rules

- Never summarize what you just read or loaded
- Never narrate your process ("Let me...", "I'll now...", "I've gathered...")
- Only output: code changes, file edits, direct answers, questions for the user
- When reading files/tasks, proceed directly to action without recap
- Maximum 50 words for non-code responses unless asked for detail
